# Linux 常用命令笔记

## 终端缩放字体

- 放大：`ctrl + shift + +`
- 缩小：`ctrl + -`

## 切换路径

- `cd`：切换目录
  - `cd 目标路径`：切换到目标路径
    - 示例：`cd /mnt/hgfs` 切换当前工作路径至 `/mnt/hgfs` 路径
  - `cd -`：切换到上一次访问的路径
    - 示例：当前处于家目录 `~`，执行 `cd /mnt/hgfs` 切换到共享目录，然后 `cd -` 回到家目录 `~`
  - `cd`：直接切换到家目录

## 列举目录/文件

- `ls`：列出目录/文件
  - `ls`：列出当前工作路径下的文件夹和文件
    - 示例：当前处于家目录 `~`，`ls` 会列出家目录下的文件夹和文件
  - `ls [参数]`：指定列出的参数
    - 示例：当前处于家目录 `~`
      - `ls -a`：列出当前工作路径下的所有文件夹和文件（包含隐藏文件）
      - `ls -l`：列出当前工作路径下的文件夹和文件的属性信息
  - `ls [参数] [目标]`：按照指定参数列出目标
    - 示例：当前处于家目录 `~`
      - `ls /mnt/hgfs`：列出指定目录 `/mnt/hgfs` 下的文件夹和文件
      - `ls -l /mnt/hgfs`：列出指定目录 `/mnt/hgfs` 下的文件夹和文件属性
      - `ls -a /mnt/hgfs`：列出指定目录 `/mnt/hgfs` 下的所有文件夹和文件

## 复制

- `cp`：复制文件或目录
  - `cp 需要拷贝的文件 目的地(目标文件)`：复制文件
    - 示例：当前处于家目录 `~`，`cp 1.txt class` 将 `1.txt` 复制到 `class` 文件夹下（前提 `class` 文件夹存在）
  - `cp 1.txt 2.txt`：将 `1.txt` 复制到 `2.txt`（并重命名）
  - `cp [参数] 需要拷贝的文件夹 目的地(目标文件夹)`：复制文件夹
    - 示例：当前处于家目录 `~`，`cp -r class class2` 将 `class` 复制到当前文件夹下（并重命名）
    - `-r`：递归复制
    - 注意：不要将文件夹复制到文件里面去

## 移动/重命名

- `mv`：移动或重命名文件/文件夹
  - `mv 需要移动的文件夹/文件 目的地`：移动文件或文件夹
    - 示例：当前处于家目录 `~`，`mv 1.cpp class/` 将当前目录下的 `1.cpp` 文件移动到 `class` 目录下
  - `mv 需要移动的文件夹/文件 新的名字`：重命名文件或文件夹
    - 示例：当前处于家目录 `~`，`mv 1.cpp 1.txt` 将当前目录下的 `1.cpp` 文件重命名为 `1.txt`
    - 注意：跨目录重命名时，新名字的前面需要带路径

## 创建普通文件

- `touch`：创建普通文件
  - 用法：`touch 文件名.扩展名` 创建普通文件
    - 示例：`touch 2.cpp` 在当前目录下创建一个名为 `2` 且扩展名为 `.cpp` 的文件
    - 注意：可以跨目录操作，在创建时可以在文件名前加路径，指定路径下创建
    - 注意：创建时要带扩展名

## 创建文件夹

- `mkdir`：创建文件夹
  - `mkdir 文件夹的名字`：创建文件夹
    - 示例：`mkdir demo` 在当前目录下创建名为 `demo` 的文件夹
    - 示例：`mkdir /demo` 在根目录下创建名为 `demo` 的文件夹
  - `mkdir 文件夹1/文件夹2/文件夹n`：创建嵌套文件夹
    - 示例：`mkdir -p demo1/demo2/demo3` 依次创建文件夹
    - `-p`：从父目录开始依次创建

## 删除

- `rm`：删除文件或目录
  - `rm 文件的完整名字`：删除文件
    - 示例：`rm 1.cpp` 删除当前目录下的 `1.cpp` 文件
  - `rm -r 文件夹的完整名字`：删除文件夹
    - 示例：`rm -r demo` 删除当前目录下的 `demo` 文件夹
    - `-r`：递归删除

## 显示当前目录的完整路径

- `pwd`：打印当前工作路径的完整路径
  - `pwd`：打印当前工作路径的完整路径

## 修改文件的权限

- `chmod`：修改权限
  - 权限表示：`rwxrwxrwx`
    - `r`：读权限
    - `w`：写权限
    - `x`：可执行权限
    - 权限组合：
      - `---`：无任何权限
      - `r--`：只读权限
      - `-w-`：只写权限
      - `--x`：不可读写，但可执行
      - `rw-`：可读写，不可执行
      - `r-x`：可读可执行，不可写
      - `-wx`：可写可执行，不可读
      - `rwx`：可读可写可执行
  - 权限组：
    - `u`：所属用户权限
    - `g`：所属组用户权限
    - `o`：其他用户权限
    - `a`：所有用户（`ugo` 的组合）
  - 用法：
    - `chmod +/-权限值 文件名`：为文件增加/删减某项权限
      - 示例：`chmod +x a.out` 为 `a.out` 增加可执行权限
      - 示例：`chmod o-x a.out` 为 `a.out` 删除其他用户的可执行权限
    - `chmod 八进制权限值 文件名`：用八进制表示权限
      - 示例：`chmod 777 a.out` 为 `a.out` 赋予所有用户全部权限
      - 八进制权限值：每一位表示一个权限组，如 `777` 表示 `rwxrwxrwx`

## 判断文件类型

- `file`：判断文件类型
  - 用法：`file 文件名` 判断文件类型
    - 示例：`file 1.cpp` 输出：`1.cpp: C source, ASCII text`
  - 常见文件类型：
    - `d`：目录文件
    - `-`：普通文件
    - `b`：块设备文件
    - `s`：套接字文件
    - `l`：链接文件
    - `p`：管道文件
    - `c`：字符设备文件

## 文件的压缩和归档

- 压缩：将多个文件或目录打包成一个文件，不改变内容大小
- 归档：将文件或目录保存在一个文件中，利用算法减小体积
- 常见压缩算法（后缀名）：`rar`、`zip`、`gzip`、`7z`、`bz`、`iso` 等
- `tar`：归档工具，可与压缩工具结合使用
  - 用法：`tar [参数列表] 压缩完成的文件的名字 需要压缩的文件列表`
  - 参数列表：
    - `-C`：指定解压缩路径
    - `-x`：释放归档文件
    - `-c`：创建归档文件
    - `-v`：显示过程信息
    - `-f`：指定归档文件名
    - `-j`：使用 `bzip` 算法压缩
    - `-z`：使用 `gzip` 算法压缩
  - 压缩：
    - `tar -zcvf xxx.tar.gz 需要压缩的文件列表`：使用 `gzip` 压缩，显示过程信息
  - 解压缩：
    - `tar -xvf xxx.tar.gz`：释放压缩文件，显示过程信息

## 帮助手册

- `man`：帮助手册
  - 用法：`man 需要查询的命令/函数`
  - 如果出现同名命令/函数：
    - `man -f 需要查询的命令/函数`：列出所有同名命令/函数
    - `man 页数 同名的命令/函数`：指定手册页
  - 在手册界面按 `q` 退出

## 临时超级管理员权限

- `sudo`：以超级管理员权限执行操作
  - 用法：`sudo 需要超级管理员权限的指令`
    - 示例：`sudo apt-get install g++`

## 切换用户

- `su`：切换用户
  - 用法：`su 用户名`
    - 示例：`su thirteen13` 切换到 `thirteen13` 用户
  - `sudo su`：切换到超级管理员用户

## 用户管理

- 增加用户：
  - `adduser`：增加用户
    - 用法：`sudo adduser 用户名`
      - 示例：`sudo adduser tempuser` 创建名为 `tempuser` 的用户
- 删除用户：
  - `userdel`：删除用户
    - 用法：`sudo userdel 用户名`
      - 示例：`sudo userdel tempuser` 删除名为 `tempuser` 的用户
    - 注意：删除用户不会清除其文件夹信息
- 用户组操作：
  - 增加组：
    - `groupadd`：增加用户组
      - 用法：`groupadd 组名`
        - 示例：`groupadd NewGroup` 新增名为 `NewGroup` 的用户组
  - 删除组：
    - `groupdel`：删除用户组
      - 用法：`groupdel 组名`
        - 示例：`groupdel NewGroup` 删除名为 `NewGroup` 的用户组
  - 添加/移除用户组：
    - 添加：`adduser 用户名 组名`
    - 移除：`deluser 用户名 组名`

## APT 软件包工具

- APT：Ubuntu 的命令行软件包管理工具，用于获取、安装、卸载、查询软件
- 工作原理：
  - 配置源服务器网址：`/etc/apt/sources.list`
  - 修改源后更新：`sudo apt-get update`
- 常用指令：
  - `sudo apt-get update`：更新软件源
  - `sudo apt-cache search 软件包名字`：搜索软件
  - `sudo apt-get install 软件包名字`：安装软件
  - `sudo apt-get remove 软件包名字`：删除软件

## 其他命令

- 关机命令：
  - `sudo shutdown now`：立即关机
  - `sudo shutdown n`：`n` 分钟后关机
  - `sudo shutdown -c`：取消定时关机
- 重启命令：
  - `sudo reboot`
- 设置密码：
  - `passwd 用户名`：为用户设置密码
- 清屏：
  - `clear`：清屏终端
  - `ctrl + l`：清屏终端
- 查看文件内容：
  - `cat 文件名`：查看文件内容
  - `cat -n 文件名`：查看文件内容并显示行号
- 查找软件：
  - `which 软件名`：查找软件路径
